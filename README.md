# Rithin M — Digital Marketing Portfolio

A free, static 5-page portfolio website:
- Home
- About
- Experience
- Skills
- Contact

## Included
- 37 campaign/performance screenshots extracted from the supplied portfolio PDF.
- CV download.
- Responsive design for desktop/mobile.
- No paid hosting, database, or framework required.

## Free publishing options

### GitHub Pages
1. Create a GitHub account and a new public repository.
2. Upload all files/folders from this project.
3. Go to Settings → Pages.
4. Select “Deploy from a branch”, choose `main` and `/root`.
5. Save. GitHub will provide the free website address.

### Netlify
Drag the project folder into Netlify's deploy area. Netlify provides a free subdomain.

## Important
The portfolio uses only information supported by the supplied CV and portfolio evidence. Client names you supplied in the brief are included as experience/niche exposure; no unsupported performance figures were invented for those clients.
